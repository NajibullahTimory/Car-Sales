# راهنمای فرانت‌اند Motrly

فرانت‌اند با React، Vite و Tailwind ساخته شده است.

## اجرا

در پوشهٔ `Frontend` اجرا کنید:

```bash
npm install
npm run dev
```

Vite روی `http://localhost:3000` اجرا می‌شود. نشانی API را در `.env` با `VITE_API_URL` تنظیم کنید؛ نمونهٔ آن در `.env.example` است.

## ساختار کد

- `src/main.jsx`: نقطهٔ شروع برنامه، بارگذاری فونت‌ها و Router.
- `src/App.jsx`: تعریف مسیرهای عمومی و خصوصی.
- `src/layouts`: سربرگ، منو، تم، زبان و قاب مشترک صفحه‌ها.
- `src/pages`: صفحه‌های بازار، ورود، پروفایل، پیام‌ها و مدیریت.
- `src/components`: کارت آگهی، جزئیات و فهرست‌های قابل استفادهٔ دوباره.
- `src/features`: کارهای هر قابلیت، مثل ورود، API آگهی‌ها و فرم ثبت آگهی.
- `src/app`: Toast و داده‌های پایهٔ بازار که از API/دیتابیس بارگیری می‌شوند.
- `src/lib`: اتصال مشترک به API.
- `src/data`: نگاشت آیکن‌ها و قالب‌بندی قیمت؛ فهرست آگهی‌ها، دسته‌ها و ولایت‌ها در JavaScript ذخیره نمی‌شوند.
- `src/i18n.js`: ترجمه‌ها، زبان صفحه و جهت نوشتار.
- `src/styles.css`: فونت‌های عمومی و رنگ textarea در تم روشن/تاریک.

آگهی‌های اولیه، دسته‌بندی‌ها و ولایت‌ها از PostgreSQL خوانده می‌شوند. برای آماده‌سازی/به‌روزرسانی این داده‌ها، از پوشهٔ `Backend` فرمان `npm run db:migrate` را اجرا کنید.
